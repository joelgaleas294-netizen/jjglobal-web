# JJ Global S.A. · Sitio web

Sitio corporativo de JJ Global S.A. (Corquín, Copán, Honduras).

- `index.html`: sitio principal (español e inglés).
- `blog/*.html`: una página por artículo, con título y descripción propios para buscadores.
- `guia-cafe-libre-deforestacion.pdf`: guía descargable.
- `og-jjglobal.jpg`: imagen para vista previa en redes sociales.
- `robots.txt`: permite la indexación.

Despliegue: Vercel (sitio estático, sin compilación). Dominio: https://www.jjglobalsa.com (jjglobalsa.com redirige a www). `sitemap.xml` y `robots.txt` usan el dominio definitivo.
